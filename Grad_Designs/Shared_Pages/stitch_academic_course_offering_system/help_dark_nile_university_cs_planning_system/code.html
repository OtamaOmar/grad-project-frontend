Operational FAQs

How are split laboratory caps (24 seats) factored into 70-student lectures? expand_more
The planner automatically forces integer rounding ceiling calculations on section subdivisions (`ceil(lecture_enrolled / 24)`). If a lecture has 49 students, exactly 3 laboratory sections are scheduled to satisfy accreditation physical lab constraints.
Can the AI side assistant modify section capacities directly? expand_more
No. The side assistant is entirely non-generative in its transaction authority. It functions strictly as an analytical vector search over indexed University Senate bylaws and semester section records. Any scheduling modifications must be staged manually via the Coordinator Console.
